# 田萝同学 (Tianluo AI) - 小红书自媒体创作全栈工作台

这是一个专为小红书自媒体创作者量身打造的商业级全栈 AI SaaS 应用，基于 Next.js 14 + Tailwind CSS + Supabase (PostgreSQL) 构建，完整复刻了「田萝同学」的全部前端视觉、动效交互以及后端数据闭环。

---

## 🚀 核心架构与功能特性

1. **创作者工作台 (Workbench - `/`)**
   - **灵感广场**：展示千赞小红书爆款模板，支持分类筛选（标题、干货科普、卡通拟人、脚本）。
   - **IP 创作中心**：真实可交互的爆款标题生成器，支持一键复制与积分实时扣减。
   - **卡通工坊 & 60天挑战**：自媒体打卡与 IP 形象扩展。
   - **积分与充值中心**：内置套餐选择与微信/支付宝原生扫码支付模拟流程，自动充值积分。

2. **管理运营后台 (CMS Admin)**
   - **用户与权限管理**：查看用户列表、角色权限与积分手动加减。
   - **AI 模型调度与通道中枢**：支持 DeepSeek、阿里云通义千问、Flux 等多通道路由与自动切站配置。
   - **财务与充值流水**：套餐订单与积分变动明细对账。

3. **官方营销落地页 (Landing Page - `/lingling`)**
   - 高转化率 Hero 区域、核心亮点介绍、套餐价格对比卡片与 FAQ 常见问题。

4. **数据库与后端数据表 (Supabase)**
   - 包含完整的 `supabase/schema.sql`，预置用户表、套餐表、订单表、积分流水表、模板库表、任务表、模型通道配置表与系统公告表。

## 📦 云端一键部署指南（零本地环境占用）

### 1. 部署前端至 Vercel (免费)
1. 登录 [Vercel](https://vercel.com)，选择 **Add New...** -> **Project**。
2. 关联并导入你的 GitHub 仓库（`lingling-app`）。
3. Framework Preset 选择 **Next.js**，直接点击 **Deploy**。
4. 约 1 分钟后即可获得专属公网访问域名（如 `https://lingling-app.vercel.app`）。

### 2. 初始化 Supabase 数据库 (免费)
1. 前往 [Supabase](https://supabase.com) 创建一个免费的 PostgreSQL 项目。
2. 进入控制台左侧的 **SQL Editor**。
3. 打开本项目中的 `supabase/schema.sql`，复制全部内容并粘贴进去，点击右下角的 **Run**。
4. 所有数据表与初始业务数据将瞬间自动初始化完成！
